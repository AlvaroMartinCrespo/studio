# **App Name**: DevFolio

## Core Features:

- Professional Profile: Create a visually appealing and informative profile showcasing your photo, a concise title, and a clear call to action.
- Project Portfolio: Display a grid of projects, each featuring an image, tech stack, problem statement, and results, filterable by technology and type.
- Detailed Project Pages: Each project has its own page with a summary, tech stack, problem/solution/results breakdown, live demo link, repository link, screenshots, code snippets, and a postmortem section.
- Technical Blog: Host technical articles with SEO optimization, covering guides, postmortems, patterns, and performance tips.
- Contact Form with Anti-spam: Implement a contact form with name, email, and message fields, along with honeypot and rate-limiting spam prevention measures.
- AI-Powered Profile Feedback Tool: Leverage generative AI as a tool to analyze your profile and projects, suggesting improvements to better highlight your strengths and experience.

## Style Guidelines:

- Primary color: Electric Indigo (#6F00FF) for a modern, tech-forward feel.
- Background color: Very light gray (#F5F5F5), near-white to ensure high readability and a clean aesthetic.
- Accent color: A slightly softer Purple (#9400D3), creating a contrast while staying in the same color family to maintain consistency.
- Headline font: 'Space Grotesk' (sans-serif) for a computerized, techy feel.
- Body font: 'Inter' (sans-serif) to provide a clean and modern look suitable for comfortable reading.
- Use a set of consistent, outline-style icons to represent skills and technologies, ensuring clarity and simplicity.
- Employ a clean and responsive grid layout with consistent spacing (4, 8, 12, 16...) to maintain visual balance and readability.
